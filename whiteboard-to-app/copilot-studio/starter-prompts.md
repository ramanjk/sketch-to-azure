# Starter prompts

| Name | Prompt |
|---|---|
| Analyze diagram | Analyze this uploaded Azure architecture diagram and summarize the detected services, connections, warnings, and assumptions. |
| Generate Bicep | Generate and compile-validate Bicep from this uploaded architecture diagram. Show any Kubernetes manifests separately. |
| Preview changes | Preview the infrastructure plan for this diagram and explain which Azure resources would be created, changed, or deleted. |
| Request deployment | Submit this validated infrastructure plan for human approval and deploy only after it is approved. |
